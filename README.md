# Tritan 🔱

> AI-Native Workflow Engine - "n8n on steroids"

## Features

- 🤖 **AI-Native**: LLMs integrados nativamente (Groq, OpenRouter, Cerebras, Gemini)
- ⚡ **Performance**: Execução paralela e streaming
- 🛡️ **Guardian System**: Agente vigilante que monitora e sugere correções
- 🎨 **UI Moderna**: Interface dark/glassmorphism com animações suaves

## Tech Stack

- **Backend**: FastAPI (Python)
- **Frontend**: React + Vite + React Flow
- **Styling**: CSS + Framer Motion

## Getting Started

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
